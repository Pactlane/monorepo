# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion about the work. Harassment, discrimination and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainers via GitHub. Maintainers will review every report and respond confidentially.
